OZON-AI选品及运营助手 - 产品需求文档 (PRD)

1. 项目概述

1.1 项目目标

打造一款集成AI能力的SaaS工具，旨在帮助OZON平台卖家大幅简化并优化“选品”与“运营”两个核心流程。通过自动化比价、成本核算、文案优化与多语言发布，提升卖家决策效率和商品上架质量。
1.2 目标用户

OZON平台的跨境电商卖家，尤其是从中国（如1688）采购货源的卖家。
1.3核心功能模块

- AI选品助手 (Workflow I): 从OZON产品分析开始，到1688智能寻源、物流成本核算，最终产出高性价比的采购决策。
- AI运营助手 (Workflow II): 基于选定的产品，进行文案的本地化、风格化优化，多语言翻译，并最终一键上架至OZON。

2. 系统架构设计

系统采用三端分离架构，明确各端职责，确保高效协同。
- 前端 (Frontend):
  - 技术栈建议: React, Vue.js 或类似现代前端框架。
  - 核心职责: 提供用户交互界面(UI/UX)，数据可视化展示，向后端发送请求，接收并渲染后端处理结果。所有用户操作的入口。
- 后端 (Backend):
  - 技术栈建议: Python (Django/Flask) 或 Node.js (Express)。
  - 核心职责: 系统的业务逻辑核心。负责用户管理、任务调度、与OZON API的交互、调用AI大语言模型（LLM）服务、数据存储与处理、向浏览器插件下发指令。
- 浏览器爬虫插件 (Browser Scraper Plugin):
  - 技术栈建议: JavaScript (Chrome Extension/Firefox Add-on)。
  - 核心职责: 作为后端的“手和眼”，在用户本地浏览器环境中执行1688等平台的爬取任务。可有效规避IP封锁、处理复杂的登录验证（Cookies）和动态加载内容（JS渲染）。

4. 数据模型 (Data Models) - 简要

- User: {userId, username, passwordHash, ozonApiKey (encrypted)}
- SelectionTask: {taskId, userId, status, ozonUrl, ozonProductInfo, createdAt}
- SupplierProduct: {productId, taskId, source ('1688'), title, price, imageUrl, productUrl, similarityScore, estimatedCost}
- LogisticsProfile: {profileId, userId, provider, transportMode, timeMin, timeMax, pricingRule (JSON)}
- OperationTask: {taskId, userId, sourceProductId, status, originalContent, optimizedContent (JSON), translatedContent (JSON)}

5. 非功能性需求

- 安全性: 用户OZON API Key必须加密存储。前后端通信需使用HTTPS。
- 健壮性: 爬虫需要有重试机制和错误处理能力，应对1688网站的结构变化和反爬措施。
- 用户体验: 前端响应要及时，长时间任务（如爬取、AI生成）需要有明确的进度反馈。
- 可维护性: 各模块间通过API解耦，爬虫插件可独立更新以应对目标网站的变化。
