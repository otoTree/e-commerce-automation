# 运营任务功能开发文档

## 1. 功能需求分析

### 1.1 前端功能概述

基于对前端运营组件的分析，系统需要支持以下核心功能：

#### 1.1.1 运营任务管理
- **任务创建**：支持基于AI选品推荐创建运营任务
- **任务列表**：展示所有运营任务，支持状态筛选和搜索
- **任务详情**：查看单个任务的详细信息和执行进度
- **任务状态管理**：pending（待处理）、in_progress（进行中）、completed（已完成）、failed（失败）

#### 1.1.2 四大核心模块
1. **商品分析（ProductAnalysis）**
   - 市场潜力分析
   - 目标受众分析
   - 竞争对手分析
   - 优化建议生成

2. **内容生成（ContentGeneration）**
   - 多平台内容适配
   - AI驱动的标题、描述、关键词生成
   - 多语言支持
   - 内容质量评估

3. **营销策略（MarketingStrategy）**
   - 营销渠道规划
   - 预算分配建议
   - KPI设定和跟踪
   - 营销时间线管理

4. **效果跟踪（PerformanceTracking）**
   - 实时数据监控
   - 转化率分析
   - ROI计算
   - 趋势预测

#### 1.1.3 AI选品功能
- **智能推荐**：基于市场数据和AI算法推荐高潜力商品
- **评分系统**：为每个商品提供AI评分和推荐理由
- **趋势分析**：分析商品市场趋势（上升/稳定/下降）
- **竞争分析**：对比竞品价格和市场定位

### 1.2 数据流分析

```
用户创建任务 → AI选品推荐 → 任务配置 → 执行四大模块 → 结果展示
     ↓              ↓           ↓          ↓           ↓
  任务管理API    选品推荐API   任务创建API  分析执行API  结果查询API
```

## 2. 后端API设计

### 2.1 运营任务相关API

#### 2.1.1 任务管理API

**GET /api/tasks**
- 功能：获取运营任务列表
- 查询参数：
  - `status`: 任务状态筛选
  - `type`: 任务类型筛选
  - `page`: 分页页码
  - `limit`: 每页数量
  - `search`: 搜索关键词
- 响应格式：
```json
{
  "success": true,
  "data": {
    "tasks": [
      {
        "_id": "task_id",
        "task_id": "TASK_001",
        "product_id": "product_123",
        "title": "智能蓝牙耳机运营任务",
        "status": "in_progress",
        "type": "full_operation",
        "progress": {
          "analysis": "completed",
          "content": "in_progress",
          "marketing": "pending",
          "tracking": "pending"
        },
        "results": {
          "analysisScore": 85,
          "contentGenerated": 3,
          "marketingPlansCreated": 0,
          "performanceMetrics": null
        },
        "created_at": "2024-01-15T10:00:00Z",
        "updated_at": "2024-01-15T12:30:00Z"
      }

      "total": 50,
      "page": 1,
      "limit": 10,

  }

```

## 3. 数据库模型设计

### 3.1 运营任务模型扩展

基于现有的Task模型，需要添加运营任务特定的字段：

```typescript
// 扩展现有Task模型
interface IOperationTask extends ITask {
  // 运营任务特定字段
  operation_config: {
    // 商品信息
    product_info: {
      product_id: string;
      product_name: string;
      product_image: string;
      category: string;
      source_platform?: string;
    };
    
    // 目标平台配置
    target_platforms: Array<{
      platform: string; // 'ozon' | 'wildberries' | 'yandex_market' | 'avito'
      config: {
        category_id?: string;
        attributes?: Record<string, any>;
        pricing_strategy?: 'fixed' | 'dynamic' | 'competitive';
        inventory_sync?: boolean;
      };
    }>;
    
    // 运营模块配置
    modules: {
      analysis: {
        enabled: boolean;
        custom_requirements?: string;
        analysis_type?: 'basic' | 'comprehensive' | 'custom';
      };
      content_generation: {
        enabled: boolean;
        target_languages: string[];
        content_types: string[];
        tone?: 'professional' | 'casual' | 'persuasive';
      };
      marketing: {
        enabled: boolean;
        budget_range?: { min: number; max: number };
        preferred_channels?: string[];
      };
      tracking: {
        enabled: boolean;
        kpi_targets?: Record<string, number>;
      };
    };
  };
  
  // 运营进度
  operation_progress: {
    analysis: 'pending' | 'in_progress' | 'completed' | 'failed' | 'skipped';
    content: 'pending' | 'in_progress' | 'completed' | 'failed' | 'skipped';
    marketing: 'pending' | 'in_progress' | 'completed' | 'failed' | 'skipped';
    tracking: 'pending' | 'in_progress' | 'completed' | 'failed' | 'skipped';
  };
  
  // 运营结果
  operation_results: {
    analysis_score?: number;
    content_generated?: number;
    marketing_plans_created?: number;
    performance_metrics?: {
      views: number;
      clicks: number;
      conversions: number;
      revenue: number;
      ctr: number;
      cvr: number;

  };
```

## 5. 实施计划

### 5.1 第一阶段：基础架构（1-2周）
1. 扩展现有Task模型，添加运营任务特定字段
2. 创建新的数据模型（ProductAnalysis, GeneratedContent等）
3. 实现基础的运营任务API路由
4. 完善AI选品API

### 5.2 第二阶段：核心功能（2-3周）
1. 实现商品分析服务和API
2. 实现内容生成服务和API
3. 实现营销策略服务和API
4. 实现效果跟踪服务和API

### 5.3 第三阶段：集成优化（1-2周）
1. 前后端接口联调
2. 性能优化和错误处理
3. 数据验证和安全加固
4. 文档完善和测试
