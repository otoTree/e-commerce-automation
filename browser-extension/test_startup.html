后台脚本日志

请打开浏览器开发者工具，查看以下位置的日志：

  1. 右键点击扩展图标 → 检查弹出内容
  2. 或者访问 chrome://extensions/ → 开发者模式 → 背景页面
  3. 查看Console标签页中的日志输出

预期的日志输出

应该看到以下日志（按顺序）：
1. "后台脚本已加载，开始初始化"
2. "扩展管理器未注册，开始初始化..."
3. "使用已存在的扩展ID" 或 "生成新的扩展ID"
4. "扩展注册成功" 或 "扩展注册失败"（如果后端未启动）
5. "心跳检测已启动"
6. "任务轮询已启动"
7. "扩展管理器初始化完成，扩展ID: xxx"
8. "后台脚本已加载"
